# dev-craft

> 构建软件的方法与技巧合集。

这里收集的**不是教程**，而是来自真实项目的**工程实践笔记**——某个具体问题怎么想、怎么权衡、最终落地成什么代码。
每篇都尽量提炼成可复用的「方法」，而不只是贴一段某项目的实现。

## 收录标准

- 必须是**踩过坑、测过、在真实产品里跑过**的结论；
- 能抽象成一条可迁移的「方法 / 反模式」；
- 附带最小可验证的代码骨架，方便直接套用。
